## 本地真实 HTTP / WebSocket 联调

### 无模型密钥服务

使用隔离的本机 SQLite 测试库，不加载任何模型密钥：

- `/healthz`、登录、个人档案、公开配置、12 个场景、会话列表、记忆列表与用量接口通过。
- 公开配置不包含供应商模型 ID 或 API Key。
- 实际 WS 输入收到 `model_not_configured` 与 `response.done: failed`，而非伪造回复。
- 结束后的学习者文字与会话状态落库。
- 已使用 ticket 再次建立连接返回 HTTP 403。

### 合成语音服务

仅测试脚本注入替身引擎，返回明确标注的测试文字与 24 kHz 正弦波 WAV；生产代码没有内置演示回复。它验证的是传输、客户端播放器与状态机，**不是 Gemini 语音质量或真实首音延迟**。

- 音频格式、分段顺序验证通过。
- 模拟只确认首段再取消，服务端仅保留首段且标记中断。
- 浏览器实际播放器完成回调触发确认，服务端保留了完整的两段测试回复。

## 浏览器已实测

本地 Web 客户端连接合成服务，使用临时测试账号：

- 空/非法服务地址和空邮箱校验。
- 服务器健康检查、登录、三步首次档案设置；目标与兴趣保存到服务端。
- 首页、12 个场景列表、角色/目标/常用表达详情。
- 场景开场、文字输入、合成音频播放、字幕、等待输入、目标进度更新；通过 REST 核对播放确认后的历史。
- 历史详情、继续原会话、不重播旧音频、不增加会话数量；实际 WS 消息携带原 `session_id`。
- 确认结束并正常返回历史详情；修复了返回拦截导致的递归卡死。
- 深色主题与减少动效设置，检查本地偏好保存；浅色与深色画面均检查。
- 记忆暂停后保留两条事实；暂停期间删除单条，核对服务端仅剩另一条事实。
- 长时间后台等待后显示断线/重连入口。
- 最终受测页面控制台未见运行错误。

浏览器预览缓存曾加载旧构建；最终回归使用强制刷新。更新 Web 部署后，也应确认客户端实际加载了新版本。注册、管理员发邀请、全部遗忘及服务器切换没有逐项完成浏览器点击验收，其服务端/数据层相关行为有自动化覆盖。
