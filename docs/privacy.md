# 隐私与数据流

Lango 是可自部署的英语练习应用，不是离线模型。启用 Google 引擎意味着部署服务器会向 Google 发送完成推理所需的数据。自部署并不等于数据从不离开自己的机器。

## 数据去向

- 手机：保存服务器地址、登录凭据及界面设置。模型供应商密钥只在服务端，不发送给 App。
- 服务端：保存账号、学习偏好、场景与会话文字记录、使用量、长期记忆和记忆处理任务。
- 原始麦克风音频：在本轮对话内存中处理，不由 Lango 主动写入持久化录音文件。
- Gemini 文本 / Live 模型：收到当前语音或文字、必要的历史文字、学习档案、导师提示词和选出的长期记忆。
- Gemini TTS：收到待朗读的回复文本以及音色等生成参数。
- Mem0：使用开源库在自己的 worker 内运行；提取和向量化所需文本仍会发送给配置的模型服务。Mem0 遥测关闭。它不是 Mem0 托管云服务。

不要在练习中提供密码、API Key、银行卡号或其他不必要的敏感数据。记忆提取提示词要求忽略凭据与敏感信息，但模型不是可靠的脱敏安全边界。

## 记忆与遗忘

记忆开关控制长期记忆的使用及新增；关闭不是删除。记忆页面支持逐条删除和全部遗忘。删除会立即撤销应用读取路径，并使旧 epoch 的异步任务失效；上游向量的物理清理需要 worker 正常运行。Mem0 的冗余原始消息/变更历史不持久写入磁盘。

**遗忘长期记忆不等于删除聊天记录、学习档案或备份。** 这些独立数据仍可能保存在数据库；继续旧会话也会带上它的历史文字。需要彻底抹除时，部署者还必须清理相应会话、账号数据和备份。首版没有完整账号注销/导出流程，公开运营前需补充适用的数据权利处理机制。

场景扮演对话不进入个人传记记忆提取，避免把“扮演求职者 / 病人”的虚构台词当成真实事实。模型可能误记普通对话，请使用记忆页检查和删除。

## 部署者责任

- 使用 HTTPS，保护数据库与备份；LAN HTTP 只用于可信网络测试。
- 不把令牌、一次性 WebSocket ticket、密码、模型密钥、原始音频或完整聊天内容写入访问日志。
- 邀请码和用户配额不替代公开服务所需的完整滥用防护、法律审核和运营支持。
- 使用前阅读当前 [Gemini API 服务条款](https://ai.google.dev/gemini-api/terms)、[可用地区](https://ai.google.dev/gemini-api/docs/available-regions)与数据使用说明。免费/付费计划、地区、年龄限制可能不同且可能变化；不要依赖旧会话中的价格或条款摘要。
- 供应商保留的数据、第三方日志和已有备份无法通过 App 的“遗忘”按钮自动清除。

## 语音体验边界

首版以按轮对话为基本交互，不承诺人类电话式零延迟。半级联引擎先生成文字再合成音频；Live 引擎使用原生音频接口，但也按轮组织。VAD、蓝牙、外放回声、自动增益和系统音频路由依设备而异，必须在真机测试。模型回复与轻量纠错仅供学习，不代表权威发音评测或考试评分。
